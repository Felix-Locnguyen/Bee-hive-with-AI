**Existing contracts to consume (do not change backend):**

```
POST /api/cameras/{hive_id}/stream-token
  → { token, expires_in, stream_url }   # stream_url already includes ?token=
GET  /api/cameras/{hive_id}/stream?token=…   # multipart/x-mixed-replace
GET  /api/hive-alerts/latest?hive_id=…  → HiveAlertRead | null
GET  /api/hive-alerts/count?hive_id=…   → { total, unacknowledged }
GET  /api/hive-alerts?hive_id=&unacknowledged=&limit= → list
PUT  /api/hive-alerts/{id}  body { is_acknowledged: true }
```

`HiveAlertRead`: `{ id, hive_id, alert_type, confidence, image_path, image_url, is_acknowledged, acknowledged_at, created_at }`

---

## Goal

On **HiveDetail only**:
1. **Kiểm tra ong** → mint token → open bottom Sheet with live MJPEG `<img>`.
2. **Latest evidence block** → poll `GET /api/hive-alerts/latest` (real image, label, conf, time).
3. **Enlarge / lightbox** for the evidence image (reuse Sheet).
4. **Acknowledge** action (`PUT … {is_acknowledged:true}`).
5. Clear loading / error states (no camera, 503 capacity, token expired, network).

Leave Honeycomb / Hives list rows untouched.

## Implementation

### 1. Extend API client — `frontend/src/services/api.js`

Add (follow existing `request()` style):

```js
// Camera AI evidence
getLatestHiveAlert: (hiveId) =>
  request(`/api/hive-alerts/latest?hive_id=${hiveId}`),
getHiveAlertCount: (hiveId) =>
  request(`/api/hive-alerts/count?hive_id=${hiveId}`),
getHiveAlerts: (params = {}) => { /* hive_id, unacknowledged, limit → query */ },
acknowledgeHiveAlert: (alertId) =>
  request(`/api/hive-alerts/${alertId}`, {
    method: 'PUT',
    body: JSON.stringify({ is_acknowledged: true }),
  }),

// Live camera (Flow B)
createStreamToken: (hiveId) =>
  request(`/api/cameras/${hiveId}/stream-token`, { method: 'POST' }),
```

### 2. New component — `frontend/src/components/LiveCameraSheet.jsx`

Self-contained live view passed into `openSheet(<LiveCameraSheet hiveId={…} />)`:

- On mount: `createStreamToken(hiveId)` → set `streamUrl` from response.
- Render `<img src={streamUrl} alt="Camera trực tiếp" className="live-cam" />` (browser handles MJPEG).
- On unmount / sheet close: set `src` to `''` then `undefined` so the connection aborts immediately.
- States:
  - loading (minting token)
  - error 404 “Chua co camera…” / missing video file
  - error 503 “Da dat gioi han xem dong thoi…” (capacity)
  - error 401/403 token (should not happen on fresh mint; show retry)
  - generic network failure + **Thử lại** button (re-mint token)
- No Authorization header — query token only (already in `stream_url`).

### 3. New component — `frontend/src/components/EvidenceAlert.jsx`

Props: `alert` (HiveAlertRead|null), `onAck`, `onEnlarge`, `loading`.

- Null state: “Chưa có cảnh báo camera AI” (or hide section if preferred — show empty state for clarity).
- Card content:
  - thumbnail `<img src={alert.image_url} …>` (relative → `/storage/...` already proxied by Vite)
  - `alert_type` + `confidence`% + relative time (`created_at`)
  - badge **Đã xử lý** if `is_acknowledged`, else button **Đã xử lý** → `onAck`
  - click thumbnail → `onEnlarge(alert)` opens lightbox Sheet with full image + meta
- Vietnamese labels only (match existing style; no i18n lib).

### 4. Wire into `frontend/src/pages/HiveDetail.jsx`

**State**
```js
const [latestAlert, setLatestAlert] = useState(null);
const [alertLoading, setAlertLoading] = useState(true);
const [liveOpen, setLiveOpen] = useState(false); // optional if using sheet only
```

**Polling** (only while HiveDetail mounted):
- Immediate fetch + `setInterval` every **8s** calling `api.getLatestHiveAlert(hiveId)`.
- Clear interval on unmount / `hiveId` change.
- Ignore errors after first load (keep last good payload); show subtle error only if never loaded.

**UI placement (replace mock detection section ~lines 396–409)**
1. New section **“Camera AI · Sinh vật lạ”**:
   - Primary button **Kiểm tra ong** → `openSheet(<LiveCameraSheet hiveId={hiveId} />)`.
   - Below: `<EvidenceAlert … />` with real latest alert.
2. Keep mock `hive.det` / `BboxOverlay` **only as fallback** when `latestAlert === null && !alertLoading` **and** mock data exists — or remove mock det block entirely once real data path works (prefer: show real empty state; drop mock det to avoid dual sources of truth).
3. Acknowledge handler:
   ```js
   const handleAck = async (alert) => {
     try {
       await api.acknowledgeHiveAlert(alert.id);
       setLatestAlert((a) => ({ ...a, is_acknowledged: true, acknowledged_at: new Date().toISOString() }));
       showToast('Đã đánh dấu xử lý');
     } catch (e) {
       showToast(e.message || 'Không xử lý được');
     }
   };
   ```
4. Enlarge handler: `openSheet(<img src={alert.image_url} className="lightbox-img" alt=… />)` + short meta line; close via existing scrim/Escape.

**Cleanup**
- Interval cleared in `useEffect` return.
- When leaving page mid-stream, Sheet unmount → `LiveCameraSheet` unmount → clear `img.src` (server `BackgroundTask` also releases slot).

## Verification (manual E2E)

1. Backend: `cd backend && python run.py` (port 8005; needs Postgres + weights path from config).
2. Frontend: `cd frontend && npm run dev` (port 3000, proxies `/api` + `/storage`).
3. Open `http://localhost:3000/hives/{id}` for a hive with `camera_config` (seeded hives 1–7 use DEMO_1/2/3).
4. **Evidence block**
   - Within ~8s shows latest alert (or “chưa có” for DEMO_1-only hives if no hornet hits).
   - Thumbnail loads via `/storage/captures/...` (200).
   - Click thumbnail → lightbox sheet with full image; Esc/scrim closes.
5. **Acknowledge** → button flips to “Đã xử lý”; refresh still shows acked state.
6. **Kiểm tra ong**
   - Sheet opens with live looping MJPEG (DEMO video).
   - Close sheet → Network tab shows stream request cancelled; open again works (slot released).
   - Open 6 concurrent streams (or lower `MAX_CONCURRENT_STREAMS` temporarily) → 503 message with retry.
7. **Polling**: new worker alert (wait ≤ cooldown 90s on a DEMO_2/3 hive) appears without full page reload.
8. Navigate away mid-stream → no leftover stream in backend logs / slot count recovers.
9. Regression: hive list, honeycomb, sensor chart, record form still work; no new console errors.
